# FixNear Contact Support

## Run locally
1. Extract this ZIP.
2. Open the folder in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown in the terminal.

The FixNear logo is included in `public/fixnear-logo.png`.

Note: The support form currently demonstrates frontend validation and a success state. Connect an API to store or email submitted requests.
